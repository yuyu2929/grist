# Grist 理论设计：积分式矢量-栅格翻译

> 版本：1.0 · 2026-10-20
>
> 本文档给出 Grist 的形式化设计：格积分语义、覆盖核算法（条带认证-裁剪积分）、
> 混合格表示、聚合金字塔一致性定理、内容寻址与增量传导、复杂度与确定性分析。

---

## 1. 格积分语义（Cell-Integral Semantics）

栅格 G 由原点 O=(x₀,yₜ)（左上角）、格距 s、格数 (W,H) 定义。
格 (i,j)（列 i，行 j，行 0 在顶）对应半开矩形

    R(i,j) = [x₀+is, x₀+(i+1)s) × [yₜ-(j+1)s, yₜ-js)

对要素集合 F，每格输出**测度份额列表**（coverage mixture）：

    M(i,j) = ( P_ij, L_ij, A_ij )
    P_ij = [(fid, 计数)], L_ij = [(fid, 长度)], A_ij = [(fid, 面积)]

即每格分别记录：落在格内的点要素计数、线要素长度、面要素面积（绝对量纲，
非归一化）。占比 φ = 测度 / s² 在读取时派生。三类语义都是**积分**而非采样：

| 要素 | 测度 μ_f(R) | 计算方式 |
|---|---|---|
| 点 | \|{p ∈ f : p ∈ R}\| | 半开规则逐点归属，精确 |
| 线 | length(f ∩ R) | 线段-矩形参数化裁剪（Liang–Barsky），精确 |
| 面 | area(f ∩ R) | 条带认证-裁剪积分（§3），解析精确 |

**半开规则**（确定性的关键）：点在格 (i,j) 内 ⟺ x₀+is ≤ px < x₀+(i+1)s 且
yₜ-(j+1)s ≤ py < yₜ-js。因此每点恰属一格（在定义域内）；域外点
（px < x₀ 或 px ≥ x₀+Ws 或 py > yₜ 或 py ≤ yₜ-Hs）不属于任何格，
由 bake 阶段显式报数，不静默丢弃。

**域覆盖推论**：左/底边包含、右/顶边排除的半开域，宽 W 无法严格包含
跨度恰为 W 的闭数据。所以"域覆盖数据"必须带余量：`fit_grid` 默认按
域尺寸 1e-9 自动 padding，守恒因此精确成立；`pad=0` 是显式退出
（域与数据 bbox 重合，贴边几何的边界重合部分落在域外）。

## 2. 为什么不用"格心规则"和"超采样"

- 格心规则（GDAL 默认）是积分的**有偏采样**：小块误差可达十分之一量级且
  非随机（同形地块平移几米即结果不同，见 RESEARCH.md §2.4）。
- 超采样是**无界统计逼近**：误差 ~ 1/√N 无确定性上界，成本 O(N)。
- 精确裁剪（逐格 Sutherland–Hodgman + shoelace，exactextract 的朴素版）
  精确但每格 O(E)，且格间不共享工作。

Grist 的立场：解析积分在数学上可达且不贵——关键观察是**绝大多数行条带
根本不与多边形边界相交**。

## 3. 覆盖核：条带认证-裁剪积分（SCCI）

> Strip Certification & Clipping Integration。
> 与 exactextract 的"环遍历 + 格内面积链接"目的部分重合（都求精确覆盖率），
> 机制不同：exactextract 逐格链接 traversal 端点成闭合多边形；
> SCCI 按行条带整体认证，仅对跨界条带做裁剪。该差异是实现级的；
> Grist 的新颖性主张在 §5–§7 的系统构造，见 RESEARCH.md §4 的诚实对照。

### 3.1 算法

输入：多边形 ring 列表 R₁..Rₙ（外环+岛环，GeoJSON 约定），栅格 G。
输出：{(i,j): 面积}（仅非零格）。

0. **定向归一化**：计算每环嵌套深度 d（顶点对其余环的奇偶测试，bbox 预过滤），
   按 (-1)^d 定向（外环 CCW、洞 CW、洞中岛 CCW……）。此后异或（even-odd）区域的
   面积 = 各裁剪后环的**签名 shoelace 面积之和**——输入环向从此无关。
1. **候选行**：多边形 bbox 覆盖的行（bbox 单元范围保守扩张，杜绝浮点漏格）。
2. **自底向上扫掠**：维护活动边集（y 跨度与当前条带相交的边）。
   只有自底向上时，进入条件（ymin ≤ yb，yb 递增）与退出条件（ymax < ya，ya 递增）
   同时单调，标准活动边扫掠才成立；自顶向下会永久逐出底部边（DEVLOG bug #1）。
3. **认证条带**（活动边为空）：覆盖 x 集在整个条带内恒定，一次奇偶测试
   决定整行 bbox 列范围填 0 或整格面积。
4. **未认证条带**：边界穿过条带 ⇒ 覆盖集 I(y) 随 y 变化，**必须精确裁剪**
   （在 yc 处采样对斜边不精确——DEVLOG bug #2，见引理 2'）：
   a. 将各环裁剪到条带（Sutherland–Hodgman，O(环长)）；
   b. 对条带碎片 bbox 覆盖的每格：若无碎片边进入该格 ⇒ 格心奇偶测试定 0/整格；
      否则将碎片裁剪到格的 x 范围，累加签名 shoelace 面积。

### 3.2 正确性

**引理 1（条带认证）**：若活动边集为空（没有任何边的 y 跨度与 S_j 相交），
则 S_j 与多边形边界不相交，故 S_j 完全位于多边形内部或外部；中点奇偶值
即为整行值。且若中点在内，则整个 bbox 列范围都被覆盖（否则 bbox 列范围内
存在边界点，与该点处的边穿越条带矛盾）。
*证明*：S_j（截断于网格 x 范围后）是连通开集；若边界不经过它，则它整个
含于 int(P) 或 ext(P)（边界与一侧开区域的补集关系）；奇偶测试在连通分量上
恒定。∎

**引理 2'（未认证条带不可采样）**：若条带被边穿越，则覆盖集 I(y) 在条带内
非常量；在 yc 处采样的误差为"斜条"面积，对斜率 m 的边界边 ≤ m·h²/2。
*证明*：I(y) 的端点即边界穿越点 x(y)，随 y 线性移动；
|I(y) − I(yc)| ≤ m·|y − yc|，在条带上积分即得。∎
（推论：轴对齐多边形的内部条带恰好恒定，故"看起来"精确——这正是 bug #2
 初期骗过简单测试的原因。实现因此对未认证条带一律走精确裁剪。）

**引理 3（定向归一化）**：环按 (-1)^深度定向后，异或区域面积
= Σᵢ 签名 shoelace(环ᵢ ∩ 区域)。
*证明*：对嵌套深度归纳。深度 0 外环 +A；深度 1 洞 −A；深度 2 洞中岛 +A……
符号交替即容斥展开。∎

**定理 1（SCCI 精确性）**：SCCI 输出的每格面积等于 area(f ∩ R(i,j))
（浮点精度内，实测对 shapely oracle ≤ 1e-12）。
*证明*：认证行由引理 1；未认证行的清洁格由格心奇偶（无碎片边进入 ⇒
整格同在内部或外部）；其余格由引理 3 的精确裁剪和。∎

**语义注记（even-odd vs GEOS hole-list）**：Grist 的环语义是奇偶语义：
洞中岛是岛（+面积）。GEOS 的 `Polygon(shell, holes)` 把内层环一律当洞
（洞中岛得负面积，且该输入在 GEOS 中本身 invalid）。Grist 选择 even-odd：
它对输入环向无要求，且给出拓扑正确的岛解释。该差异记录于 DEVLOG。

### 3.3 线的精确长度

线段 p→q 与矩形 R 的交：参数化 p+t(q-p)，t∈[0,1]，对 R 的四个半空间
依次裁剪得 t 区间 [t₀,t₁]，交长 = |q−p|·(t₁−t₀)。候选格 = 线段 bbox 覆盖
的格（每格 O(1) 测试）。所有格上交长之和 = 线总长（格构成域的分划）。
Bresenham/Wu 类算法给出的是"点亮"而非长度积分，语义不同（RESEARCH.md §2.4）。

## 4. 混合格表示（Coverage Mixture）

每格存储 (fid, 测度) 稀疏列表而非单值：

- **重叠不丢失**：两地块重叠格各自保留面积份额；GDAL 的 REPLACE/ADD
  分别丢失前者或混淆量纲。
- **烘焙不决策**："哪类赢"（多数类 / 最大面积 / 图层优先）是**读取策略**，
  在查询时施加，而非烘焙时固化。SwissCrop25 的"先聚合后取多数类"
  （RESEARCH.md §2.2）因此成为混合格上的一个内置策略。
- **稀疏存储**：纯 0 格不存储（认证行的整行同值可用行前缀和进一步压缩，
  见 §7 工程注记）。

## 5. 聚合金字塔（Aggregated Pyramid）

层 ℓ 的格 C 覆盖 4 个层 ℓ-1 的子格 c₁..c₄（2×2 分块；边缘不整时按实际
相交子格聚合）。聚合规则：**按 fid 测度求和**（点数求和、长度求和、
面积求和），绝对量纲不变。

**定理 2（聚合一致性）**：μ_f^(ℓ)(C) = Σᵢ μ_f^(ℓ-1)(cᵢ)，从而
μ_f^(ℓ)(C) = Σ_{c ⊆ C} μ_f^(0)(c)。
*证明*：计数测度、长度测度、面积测度在互不相交区域上均可加；子格两两
不交且 ∪cᵢ = C。∎

**推论 5.1（层间无漂移）**：粗层格值是细层格值的精确函数——不存在重采样。
类别混合的权重和在各层保持面积加权语义，从根本上消除 COG 式金字塔
"对类别影像取均值造出 6.5 类"的静默缺陷（RESEARCH.md §2.1）。
**推论 5.2（顶层即总量）**：金字塔顶格的测度和 = 全体要素的测度总和
（面积守恒、长度守恒、计数守恒），可作为烘焙的全局校验和。

## 6. 内容寻址瓦片与增量传导

- **瓦片**：每层切分为 T×T 格（T=16；边缘瓦片裁剪）。
- **瓦片相对坐标**：瓦片字节内的格坐标是**瓦片内相对坐标** (i mod T,
  j mod T)，瓦片在层内的位置只存在于 manifest。这是内容寻址的前提：
  位置是外在属性，混进内容哈希会让不同位置的重复图案无法去重
  （DEVLOG BUG 13）。
- **规范序列化**：瓦片字节 = 头部（层、tw、th）+ 按 (行,列) 序的格；
  每格 = 按 fid 升序的三个份额列表，double 用 IEEE-754 小端原样编码
  （计算全程确定性浮点，无并行归约乱序）。
- **内容寻址**：tile_hash = blake2b(canonical_bytes, 32)；金字塔 =
  {tile_hash → bytes} 的内容存储 + manifest（每层 (i,j) → tile_hash）。
- **增量传导**：编辑要素 f 后，脏瓦片 = f 的 bbox（保守外扩一格）触及的
  层 0 瓦片；与脏瓦片重叠的要素各算一次覆盖（缓存），重算脏瓦片；对每个
  哈希变化的瓦片，向上重算其 2×2 父瓦片，逐层传播直至无变化。
  未变瓦片哈希不变 ⇒ 去重（重复图案共享字节）、diff（两版金字塔的
  哈希集差）、完整性（重算即验证）。
- **更新 ≡ 新烘焙**：父瓦片重算与全量聚合使用同一规范子格序
  (0,0),(1,0),(0,1),(1,1)（DEVLOG BUG 5：浮点求和顺序敏感，两路径
  必须一致才能保证字节级相同）；序列化只写 manifest 引用的 blob
  （DEVLOG BUG 7）。二者合起来给出承诺：**更新后的金字塔与同状态
  新烘焙字节级相同**，测试钉死。

## 7. 复杂度与确定性

设多边形边数 E、周长 P、格距 s、栅格 W×H、环数 R、活动边峰值 A。

| 阶段 | 复杂度 | 说明 |
|---|---|---|
| 定向归一化 | O(R²E) 最坏；bbox 预过滤后典型 O(RE) | R 为环数，GIS 多边形通常 R≤10 |
| 候选行 | O(1)（bbox） | |
| 扫掠维护 | O(E log E + H + Σⱼ Aⱼ) | 自底向上，指针进边 + 均摊出边 |
| 认证条带 | O(1)/行（一次奇偶测试 O(E)） | 认证出现在垂直间隙；大多边形内部条带通常被垂直边穿越（未认证），但每行只付活动边代价（矩形仅 2 条） |
| 条带裁剪 | O(未认证条带数 × E) | |
| 逐格决定 | O(候选格数 × 碎片边数) | 清洁格 O(1) 奇偶；仅边界格付裁剪 |
| 聚合 | O(总格数) 每层 | 线性扫子格 |
| 增量编辑 | O(受影响瓦片 × 层数) | 局部传播 |

**确定性**：纯串行浮点、固定遍历序、固定求和序（粗格的四个子格按规范序
(0,0),(1,0),(0,1),(1,1) 合并——全量聚合与增量父瓦片重算走同一顺序）
⇒ 同输入字节级同输出。文件级 content_hash = blake2b(全文件)。

**确定性也适用于"裁判代码"**：任何对浮点求和的导出量（守恒校验的
`totals()`、基准的聚合漂移指标）同样按排序序遍历并用 `math.fsum`
精确舍入——否则 set/dict 的进程级哈希序会把 1 ulp 的不确定性引进
本该确定的结论（DEVLOG BUG 16）。字节级确定性只有覆盖到验证工具
本身才是完整的承诺。

**工程注记（v1 取舍）**：认证行的稀疏性（仅存非零格 + 行同值压缩）与
长对角线的格遍历（当前为 bbox 走查）是两处已知的可优化点，
以实现简洁与正确性优先，记录于 DEVLOG。

## 8. 与 Weft 的关系

Weft（前序项目）解决"矢量-栅格统一存储"：要素一次存储 + 叶子积分场。
Grist 解决"矢量到栅格的翻译"：输入即纯矢量，输出为可寻址的金字塔栅格资产。
两者共享的设计哲学（积分语义、内容寻址、确定性）但数据模型与核心算法
完全不同：Weft 的核心是分区四叉 + 地址键；Grist 的核心是 SCCI + 聚合 +
瓦片寻址。Grist 不依赖 Weft，可独立成立。
